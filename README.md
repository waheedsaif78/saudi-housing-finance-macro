# saudi-housing-finance-macro

[![pipeline](https://github.com/waheedsaif78/saudi-housing-finance-macro/actions/workflows/ci.yml/badge.svg)](https://github.com/waheedsaif78/saudi-housing-finance-macro/actions/workflows/ci.yml)

This project links three official Saudi data sources:

- GASTAT's **Real Estate Price Index (RPI)**
- SAMA's **new residential mortgages to individuals**
- **policy and interbank rates** (repo, 3M SAIBOR)

It answers four questions:

1. Do mortgages lead prices?
2. Has the finance mix (villa, apartment, land) tracked prices by property type?
3. How sensitive is mortgage volume to rates?
4. What do the next four quarters look like under flat, −50bp and +50bp SAIBOR scenarios?

**Findings, recommendations and limitations (Arabic):** [`07_insights.md`](07_insights.md)

> **ملخص بالعربية:** يربط المشروع مؤشر أسعار العقارات الرسمي بالتمويل العقاري السكني الجديد وأسعار الفائدة. أبرز النتائج:
> - التمويل لا يسبق الأسعار.
> - المؤشر العام يقوده سعر الأراضي، ووزن الأرض السكنية فيه 46%.
> - كل 50 نقطة أساس في سايبور تحرّك حجم التمويل في السنة التالية بنحو ±3–6%.

## Quick start

```bash
git clone https://github.com/waheedsaif78/saudi-housing-finance-macro.git
cd saudi-housing-finance-macro
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run_all.py        # steps 01 -> 06, under a minute
python -m pytest -q      # data-integrity and regression checks
```

Python 3.11 or later. CI runs the full pipeline and the tests on Python 3.11 and 3.13.

## Repository layout

```
01_acquisition.py   raw files -> data/processed/long.parquet (date, freq, series, value, unit, source, table)
02_harmonize.py     monthly -> quarterly, CPI-deflated values, mix shares, RPI splice, policy dummies
03_eda.py           figures, YoY table, STL decomposition, Ramadan / seasonal effects
04_relationships.py ADF/KPSS, cross-correlation, Granger, rate sensitivity, mix vs price, policy dummies
05_forecast.py      Naive / ETS / ARIMAX(+SAIBOR) with rolling-origin backtests
06_scenarios.py     SAIBOR flat / -50bp / +50bp -> mortgage volume over the next 4 quarters
07_insights.md      findings and recommendations (Arabic)
src/shfm/           project code: extractors, data-driven windows (config.py), models
src/dpu/            Data Processing Unit (vendored): parses XLSX/CSV/PDF/... into clean DataFrames
data/raw/           official source files (inputs)
outputs/            figures/*.png and tables/*.csv (committed so results are readable on GitHub)
tests/              pytest checks
```

`data/processed/` is regenerated by `run_all.py`, so it is not committed.

## Updating with new releases

1. Download the new release into `data/raw/`, keeping the file-name pattern:
   - `sama__Monthly_Bulletin*.xlsx`
   - `gastat__REPI_Q<n>_<yyyy>*.xlsx`
   - `gastat__CPI_Tables_<Mon>_<yyyy>*.xlsx`
2. Run `python run_all.py`.

The pipeline always uses the latest file for each pattern. All analysis windows and forecast dates come from the data (`src/shfm/config.py`), so nothing needs editing.

If SAMA has published only one or two months of the next quarter, step 06 nowcasts that quarter from those months.

`07_insights.md` is written by hand. Re-read its numbers against `outputs/tables/` after each update.

## Data sources

| File | Source | Coverage in this snapshot |
|---|---|---|
| `sama__Monthly_Bulletin.xlsx` | SAMA [Monthly Statistical Bulletin](https://www.sama.gov.sa/en-US/Statistics/Pages/MonthlyStatistics.aspx): tables 12f (banks), Finance Companies 7, 5-6 (rates) | monthly, to Aug-2026 |
| `gastat__REPI_Q2_2026.xlsx` + PDF | GASTAT [Real Estate Price Index](https://www.stats.gov.sa/en/statistics-tabs?tab=436312&category=121920), 2023=100, new methodology | 2021Q1–2026Q2 |
| `gastat__CPI_Tables_Sep_2026.xlsx` | GASTAT [Consumer Price Index](https://www.stats.gov.sa/en/statistics-tabs?tab=436312&category=121421), table 5.1 (general, housing, actual rents) | monthly, 2013–Sep-2026 |
| `kapsarc__real-estate-indices.csv` | Old RPI (2014=100), re-published by [KAPSARC Data Portal](https://data.kapsarc.org) | 2014Q1–2024Q4 |
| `kapsarc__real-estate-price-index-by-sector-2023-100.csv` | KAPSARC copy of the new RPI, used only as a cross-check | 2021Q1–2026Q1 |

The raw files are public statistics. They are included unmodified so that results can be reproduced, and they remain subject to the publishers' terms of use. See the [SAMA disclaimer](http://www.sama.gov.sa/en-us/pages/disclaimer.aspx) and GASTAT's portal terms.

## Validation

- **SAMA aggregation:** monthly mortgage sums reproduce SAMA's own quarterly totals exactly (84 lender-quarters, 0.000% gap).
- **KAPSARC copy:** the KAPSARC copy of the new RPI matches GASTAT's workbook exactly (63 points).
- **Published-figure checks:** the tests assert two published figures:
  - GASTAT's Q2-2026 headlines: +1.3% general, +6.3% residential plots, −9.7% villas.
  - The 64% villa share of bank mortgage value in 2024.

  These fail if a publisher later revises history.

## Methodological notes

- **RPI break.** GASTAT changed the RPI methodology from Q3-2024 (base 2023) and back-cast the new series to 2021Q1.
  - Over the overlap 2021Q1–2024Q2 the two methods disagree: the old method shows +5.5% and the new +25.1%.
  - Primary analysis therefore uses only the new series. A ratio splice at 2021Q1 is used for robustness checks only.
- **Seasonality.** Mortgage flows are seasonally adjusted with monthly STL (log, period 12, robust) before quarterly aggregation for lead/lag tests.
- **Real values.** Nominal values are divided by CPI general (2023=100).
- **Policy step dummies.** Estimated in step 04. With about 20 quarterly changes the estimates are indicative only. The dummies are:
  - RETT 5% (4-Oct-2020)
  - Riyadh land directives and the White-Land law amendment (Q2-2025)
  - Riyadh 5-year rent freeze (25-Sep-2025)
- **Ramadan dates.** Umm al-Qura start dates, accurate to about ±1 day. The 2027–28 dates are projections.
- **Small sample.** Results are indicators, not causal proof. Granger tests measure precedence, not causation.

## Data Processing Unit (dpu)

`src/dpu` is a vendored copy of the author's Data Processing Unit, which converts JSON, CSV, XLSX, XML, PDF, DOCX, PPTX and PBIX files into cleaned pandas tables.

The project reads statistical bulletins with a layout-preserving configuration (`GRID_CONFIG` in `src/shfm/common.py`). To use a different dpu checkout, set `DPU_PATH` to the folder that contains `dpu/`.
